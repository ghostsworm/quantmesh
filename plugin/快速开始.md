# QuantMesh 插件系统 - 快速开始

## 🎯 5分钟快速上手

### 1. 运行演示程序

```bash
cd /Users/rocky/Sites/opensqt_market_maker

# 运行插件系统演示
go run plugin/examples/demo.go
```

你会看到:
- ✅ 免费插件加载演示
- ✅ 商业插件加载演示  
- ✅ 许可证生成和验证演示
- ✅ 插件列表展示

### 2. 创建你的第一个插件

```bash
# 使用脚手架生成插件模板
./scripts/create_plugin.sh my_strategy

# 查看生成的文件
ls -la plugins/my_strategy/
# plugin.go        - 插件主文件
# plugin_test.go   - 测试文件
# README.md        - 说明文档
# go.mod           - Go模块配置
```

### 3. 生成商业许可证

```bash
# 为插件生成许可证
./scripts/generate_license.sh premium_ai_strategy CUST001 365 5

# 参数说明:
# premium_ai_strategy - 插件名称
# CUST001            - 客户ID
# 365                - 有效天数
# 5                  - 最大实例数
```

### 4. 验证许可证

```bash
# 编译验证工具
go build -o /tmp/license_validator plugin/tools/license_validator.go

# 验证许可证
/tmp/license_validator -key="<你生成的许可证密钥>"
```

## 💡 核心概念

### 插件类型

```go
PluginTypeStrategy  // 策略插件 - 自定义交易策略
PluginTypeAI        // AI插件 - 市场分析和预测
PluginTypeRisk      // 风控插件 - 自定义风险控制
PluginTypeSignal    // 信号插件 - 外部信号接入
```

### 许可证类型

```yaml
免费插件:
  License: "free"
  RequiresKey: false
  
商业插件:
  License: "commercial"
  RequiresKey: true
```

## 🚀 实战示例

### 场景1: 开发免费插件并开源

```bash

# 2. 实现策略
```

### 场景2: 开发商业插件并销售

```bash
# 1. 创建私有仓库
mkdir quantmesh-plugin-premium-ai
cd quantmesh-plugin-premium-ai
go mod init github.com/quantmesh-pro/premium-ai

# 2. 实现插件
# 设置: License: "commercial", RequiresKey: true

# 3. 推送到 GitHub Private
git init
git remote add origin git@github.com:quantmesh-pro/premium-ai.git
git push -u origin main

# 4. 客户购买后:
# - 生成许可证
./scripts/generate_license.sh premium_ai CUST001 365 5

# - 添加客户到私有仓库
# - 发送许可证密钥给客户
```

### 场景3: 客户使用商业插件

```bash

# 2. 获取插件
go get github.com/quantmesh-pro/premium-ai@latest

# 3. 配置许可证
cat >> config.yaml << 'EOF'
plugins:
  enabled: true
  plugins:
    - name: "premium_ai"
      enabled: true
      license_key: "eyJwbHVnaW5fbmFtZSI6InByZW1pdW1fYWkiLCJjdXN0b21lcl9pZCI6IkNVU1QwMDEi..."
      params:
        weight: 2.0
EOF

# 4. 编译运行
go build -o quantmesh
./quantmesh
```

## ❓ 常见问题

### Q: 插件系统支持哪些 Go 版本？
A: Go 1.21+

### Q: 可以动态加载插件吗？
A: 当前方案是编译时链接。如需动态加载，可以使用 Go Plugin (仅 Linux/macOS) 或 gRPC 方案。

### Q: 许可证可以破解吗？
A: 许可证使用 SHA-256 签名，密钥编译到二进制中。配合代码混淆和在线验证，安全性很高。

### Q: 如何撤销客户的许可证？
A: 
1. 从私有仓库移除客户访问权限
2. 如使用在线验证，在服务器端禁用许可证
3. 生成新版本时更改签名密钥

### Q: 支持试用版吗？
A: 支持。生成短期许可证即可:
```bash
./scripts/generate_license.sh premium_ai TRIAL001 7 1
```
