# 回测支持 K 线文件与深度风控 - 功能测试

## 实施完成的功能

### ✅ 后端扩展
1. **BacktestTask 结构体** - 增加 DataSource, KlineFile, CacheName 字段
2. **数据加载模块** - `backtest/data_source.go` 支持从 K 线文件和缓存加载
3. **深度风控** - RiskSimulator 支持 MinDepthUSDT, DepthDropThreshold 参数
4. **TaskManager** - 按 DataSource 分支加载数据，支持深度风控
5. **存储层** - 数据库表和 CRUD 方法支持新字段
6. **Web API** - 接受和校验新的数据来源参数

### ✅ 前端扩展
1. **数据来源选择** - 单选：时间范围 | K线文件 | 回测缓存
2. **K线文件列表** - 显示文件名、交易对、周期、是否含深度
3. **回测缓存选择** - 复用现有缓存列表
4. **参数校验** - 根据不同数据来源校验必填字段
5. **服务接口** - postBacktestTask 支持可选参数

### ✅ 国际化
- 中文简体/繁体、英文、德语、西班牙语、法语、韩语等多语言支持

## 测试步骤

### 1. 准备测试数据
确保 `./data/kline` 目录下有 K 线文件：
- 格式：`{interval}_{exchange}_{symbol}_{date}.csv`
- 支持 7 列（无深度）和 26 列（含深度）格式

### 2. 测试数据来源选择
1. 启动服务，访问回测页面
2. 在「1. 交易对与数据」卡片中查看是否有数据来源单选
3. 切换不同数据来源，验证 UI 是否正确显示

### 3. 测试 K 线文件回测
1. 选择数据来源：K线文件
2. 刷新文件列表，选择一个文件
3. 选择策略和参数，点击运行回测
4. 验证回测是否成功创建和执行

### 4. 测试回测缓存回测
1. 选择数据来源：回测缓存
2. 刷新缓存列表，选择一个缓存
3. 选择策略和参数，点击运行回测
4. 验证回测是否成功创建和执行

### 5. 测试深度风控
1. 使用含深度数据的 K 线文件（26 列）
2. 运行网格策略回测
3. 查看回测结果，验证是否显示深度风控介入记录

## 预期结果

1. **数据来源切换** - UI 根据选择显示对应的输入组件
2. **文件加载** - 能正确解析文件名和数据格式
3. **深度风控** - 带深度数据时自动启用深度风控
4. **兼容性** - 不影响现有时间范围回测功能
5. **错误处理** - 适当的校验和错误提示

## 已知限制

1. K 线文件路径仅支持 `./data/kline` 目录
2. 深度风控参数暂时使用默认值（MinDepthUSDT=10000, DropThreshold=0.5）
3. 前端国际化仅添加到部分语言文件

## 版本信息

本功能实现对应计划文档中的所有任务点，为系统增加了灵活的数据来源支持和更精准的深度风控能力。
