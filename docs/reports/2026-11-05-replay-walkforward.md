# 网页网格 replay 样本外验证报告

版本：`3.112.0-rc1`（开发中，未发布）。基线提交：`7de60665`。本次修改尚未提交，版本号不代表部署或真实交易验收。

## 结论与范围

本轮把 `/backtest` 页的网格参数优化接入 `UniversalOptimizer → replay walk-forward`，不重做现有网格策略，不接入 FundingCarry，不增加优化算法。旧独立 `GridSearchOptimizer` 的 legacy walk-forward 保留，不与本入口混称。

已有 `task_features.go` 提供 regime_filter、adaptive_interval、upper_bound_freeze、inventory_skew、fee_aware_spread 等参数注入；旧 ADR 的“网页回测尚未注入”判断已修正。本轮只补受限参数搜索、时间隔离与可审计结果链路。

当前隔离样本验证工程上的选参和回放行为，不能得出真实行情样本外盈利或实盘可上线结论。没有访问账户、下单、提交、推送、tag、发布或部署。

## 冻结协议

- 每折 train `[s,s+train)`、test `[s+train,s+train+test)`，步长等于测试窗；均为完整、规则、UTC 周期对齐 K 线。跨界 K 线、缺口、重复和错周期拒绝执行。
- 候选只在训练窗运行，按净收益率减逐 tick 最大回撤选择，严格同分按确定枚举顺序；仅冻结的训练胜者进入测试窗。没有按测试结果二次选参。
- 固定基线在请求时声明，并在相同数据、资本和撮合假设下运行。结果分列胜者样本内、胜者样本外、基线样本内、基线样本外及样本外超额收益。
- 每次回放新建 SPM、模拟交易所和特征状态；同额本金、空仓开始，warm-up 只允许当前窗内已闭合 K 线。撤单等待推进的操作时钟不提前开放市场特征数据。
- 净收益包含已实现及未实现盈亏，扣 maker/taker 手续费与结算资金费；期末持仓按市值计价，不模拟强平费用，不跨窗复利。
- 结果保存协议、资本、完整候选轴、基线/选中参数、训练/测试边界与 SHA-256 数据/配置/参数/实验摘要。参数快照包含费用假设和已有功能配置。
- 首版限制单向合约 grid、32 候选、12 折、100000 根输入 K 线、2000000 次 K 线评估；拒绝未知/legacy 风控轴、外部 aggTrade 路径和资金费预测/偏置信号。

## 隔离样本与负例

`backtest/optimizer/replayfixture` 固定配方 `replay-wf-synthetic-v1`：2025-01-01 UTC 起，120 根小时 K 线，基础价 2000，12 小时主周期叠加 37 小时次周期，再加每小时 +2/0/−2 漂移，分别产生上涨、横盘、下跌。次周期与 24 小时折步长不整除，测试窗不是训练窗的周期复制。每折训练 3 天、测试 1 天，共两折；每折本金 10000、杠杆 3，搜索 spacing 15/30，基线 spacing 20。固定 maker 0.02%、taker 0.04%、每 8 小时资金费 0.01%；费用口径均为模型假设。

短周期 regime 配置使特征能在每窗内完成预热；不以全数据预热代替训练/测试隔离。成交量与 K 线内路径均为合成数据，无外部 API、文件行情或真实账户状态依赖。

负例包括：

- 将首折测试窗及以后 OHLC 放大 3 倍、成交量放大 2 倍，首折训练候选指标、选中参数和训练摘要必须完全不变，测试/实验数据摘要必须改变。
- 将未来最终结算费率从 0.01% 改为 90%，此前训练和测试的下单、成交、费用及选参必须不变；完整实验摘要必须体现费用序列变化。
- 进度回调中修改原始行情、候选范围和嵌套特征配置，已冻结实验仍与未修改对照完全一致。
- 重复/缺失/错周期/偏移聚合桶、跨界窗口、测试窗重叠、超限候选、外部 tick 路径和未来费率信号配置均拒绝。
- 取消在 replay tick 循环与优化层传播，不生成成功的部分排行；SQLite 关闭重开后保留协议、基线与嵌套配置。

## 复现

从仓库根目录执行，输出目录必须尚不存在；`tmp/` 已被仓库忽略。

```bash
ruby scripts/verify_replay_walkforward.rb tmp/replay-walkforward-validation
```

生成 `report.json`、`report.md`、测试日志、三类原始 candle JSON、完整请求 JSON 和结果 JSON。JSON 中记录基线提交、dirty 工作树摘要、前后端版本以及测试前后源码稳定性；SHA-256 用于绑定复现材料，不是抵抗任意篡改的签名。

API 验证由隔离 httptest 服务挂载真实任务 handler 与优化 manager，Ruby 发起 HTTP 请求，测试 loader 使用冻结 fixture，存储与结果目录隔离；输出 JSON/Markdown。该测试不依赖公网交易所或实盘配置。

## 限制

- K 线内 O/H/L/C 路径、成交量分配和排队是假设；缺乏历史盘口/价差、真实队列位置与主动成交方向。
- 下单、撤单、回报按模拟执行；没有真实网络延迟、限流或市场冲击。未建模滑点不能视为已证实的零成本。
- 没有历史当期预测资金费率。本入口只允许预声明固定费率或最终结算序列做成本，禁止用最终结算费率提前定价或调整方向。
- 每窗独立空仓是保守隔离协议，不能解释为连续账户收益；期末未平仓与冷启动预热影响结果，必须结合分列指标解读。
- 合成上涨/横盘/下跌样本不是独立真实市场收益证据；仍缺真实冻结行情、多时期外推与实盘校准。FundingCarry、真实账户权益/费用对账及盈利验收仍属于独立证据范围。
