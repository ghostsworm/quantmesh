# 🧮 PAXG/USDT 网格交易参数优化模块设计文档

## 🏁 目标

构建一个自动化模块，用于寻找 **PAXG/USDT 网格交易策略**的最优参数组合，使得策略在历史数据中获得最高的 **风险调整后收益**。

---

## ⚙️ 一、模块设计概览

### 输入：
- 历史 K 线数据（推荐 90~180 天，1h 或 4h 粒度）
- 手续费信息（maker / taker）
- 回测函数接口 `backtest(params)`
- 参数搜索空间定义（区间、间距、仓位）

### 输出：
- 最优参数组合 `(P_low, P_high, ΔP, q)`
- 各指标统计（收益、回撤、夏普比率、成交次数）
- 热力图/曲面图（用于人工分析）

---

## 🧩 二、核心参数定义

| 参数 | 含义 | 推荐取值范围 |
|------|------|-----------|
| `P_low` | 网格下限价 | 当期价格 * (1 - 5% ~ 15%) |
| `P_high` | 网格上限价 | 当期价格 * (1 + 5% ~ 15%) |
| `ΔP` | 单格间距 | 总区间的 0.2%~1% |
| `q` | 单格仓位比例 | 资金的 1~5% |
| `λ` | 风险权重 | 0.3–0.7，用于调整目标函数 |

---

## 🎯 三、优化目标函数定义

目标函数要综合收益与风险：

\[
\text{Score} = \text{Annualized Return} - \lambda \times \text{Max Drawdown}
\]

其他可选指标：
- 夏普比率（Sharpe Ratio）
- 成交次数（Liquidity Measure）
- 手续费后净收益（Net Return）

> **目标：最大化 Score**

---

## 🧠 四、算法流程
1️⃣ 数据载入与预处理
↓
2️⃣ 定义参数搜索空间
↓
3️⃣ 调用回测函数 backtest(params)
↓
4️⃣ 计算目标函数 Score
↓
5️⃣ 记录结果 / 更新模型
↓
6️⃣ 输出最优参数 + 模型评估图表

---

## 🔬 五、推荐算法架构

| 算法 | 特点 | 适用阶段 |
|------|------|-----------|
| **Grid Search（网格搜索）** | 全局扫描，结果稳定但慢 | 初次调参 |
| **Bayesian Optimization（贝叶斯优化）** | 高效、自动聚焦优区 | 二次优化 |
| **Genetic Algorithm（遗传算法）** | 多目标优化、容错强 | 稳健性验证 |

⚙️ 2. 贝叶斯优化（主优化阶段）
利用高斯过程（Gaussian Process）预测收益空间：

python

查看全部
from skopt import gp_minimize
from skopt.space import Real

space = [
    Real(2200, 2600, name='P_low'),
    Real(2300, 2700, name='P_high'),
    Real(2, 10, name='ΔP')
]

def objective(params):
    low, high, gap = params
    score = backtest_return(low, high, gap)
    return -score  # skopt 最小化

result = gp_minimize(objective, space, n_calls=40)
best_params = result.x
