# 平仓与订单管理改造 - 实施总结

> **状态**: 已完成实施
> **版本**: v3.55.0+
> **实施日期**: 2025年2月

## 一、功能概述

本次改造实现了以下四个核心功能：

1. **平仓方式选择**：支持市价/限价平仓，状态追踪，超时重试
2. **订单管理**：启动前列出委托，支持修改/删除特定槽位
3. **交易方向选择**：单向做多/单向做空/双向交易
4. **智能挂单**：渐进式挂单，节省资金占用

## 二、已实现的功能

### 2.1 平仓方式选择

#### 后端文件
- `position/close_manager.go` - 平仓管理器
- `web/api_close_positions.go` - 平仓 API

#### API 端点
```
POST /api/v2/bots/:id/close-positions  # 平仓（市价/限价）
GET  /api/v2/bots/:id/close-records    # 获取平仓记录
POST /api/v2/close-records/:id/retry    # 重试平仓
```

#### 配置示例
```yaml
bots:
  - id: "binance:PAXGUSDT:futures"
    close_on_stop: true
    close_on_stop_config:
      method: "limit"
      price_offset: -0.1  # 卖低 0.1%
      timeout_sec: 3600
      auto_retry: true
```

### 2.2 订单管理（槽位过滤）

#### 后端文件
- `position/super_position_manager.go` - 添加槽位过滤方法

#### API 端点
```
GET    /api/v2/bots/:id/slot-filter          # 获取槽位过滤器
POST   /api/v2/bots/:id/slot-filter          # 设置槽位过滤器
POST   /api/v2/bots/:id/slot-filter/rules    # 添加过滤规则
DELETE /api/v2/bots/:id/slot-filter/rules/:index  # 删除规则
GET    /api/v2/bots/:id/slots                # 获取所有槽位
POST   /api/v2/bots/:id/slots/toggle         # 切换槽位启用状态
```

#### 使用示例
```json
// 禁用 5180 价格位的委托
POST /api/v2/bots/binance:PAXGUSDT:futures/slot-filter/rules
{
  "type": "exclude",
  "prices": [5180],
  "reason": "手动禁用"
}
```

### 2.3 双向交易 (BOTH)

#### 配置示例
```yaml
bots:
  - id: "binance:BTCUSDT:futures:both"
    direction: "BOTH"  # 同时做多和做空
```

### 2.4 智能挂单

#### 后端文件
- `position/smart_order_manager.go` - 智能挂单管理器

#### 配置示例
```yaml
bots:
  - id: "binance:PAXGUSDT:futures"
    smart_order:
      enabled: true
      max_open_orders: 3         # 最多3个开仓单
      open_order_distance: 5     # 5个间隔内
      progressive_placement: true  # 渐进式挂单
```

## 五、使用场景示例

### 场景 1：平仓方式选择
当对效果不满意需要中止平仓时：
1. 使用限价单获得更好的价格
2. 设置 1 小时超时
3. 如果超时自动转为市价单

### 场景 2：槽位过滤
当前价 5200，想屏蔽 5180 的买单，只委托 5160：
```bash
curl -X POST http://localhost/api/v2/bots/binance:PAXGUSDT:futures/slot-filter/rules \
  -H "Content-Type: application/json" \
  -d '{"type":"exclude","prices":[5180],"reason":"手动禁用"}'
```

### 场景 3：智能挂单
避免一次性挂太多订单浪费资金：
```yaml
smart_order:
  enabled: true
  max_open_orders: 3     # 只挂3个开仓单
  open_order_distance: 5  # 5个间隔内
  progressive_placement: true  # 价格移动时逐步添加
```

## 六、Bot 风控功能（新增）

### 6.1 单独 Bot 风控策略

为每个 Bot 提供独立的风控配置，可覆盖全局设置。

#### 后端文件
- `config/config.go` - 添加 `BotRiskControl` 结构
- `bot_manager.go` - 添加风控相关方法
- `position/super_position_manager.go` - 添加持仓数量检查
- `web/api_bot_risk_control.go` - 风控 API

#### API 端点
```
GET    /api/v2/bots/:id/risk-control        # 获取风控配置
PUT    /api/v2/bots/:id/risk-control        # 更新风控配置
POST   /api/v2/bots/:id/pause-opening       # 暂停开仓
POST   /api/v2/bots/:id/resume-opening      # 恢复开仓
GET    /api/v2/bots/:id/position-status     # 获取仓位状态
```

#### 配置示例
```yaml
open_position_control:
  max_position_quantity: 4  # 全局：最多 4 个币
  bot_risk_control:
    enabled: true
    max_position_quantity: 4    # Bot 独立：最多 4 个 PAXG
    max_position_value: 1000    # Bot 独立：最多 1000 USDT
    max_position_layers: 10     # Bot 独立：最多 10 层
    stop_loss_ratio: 0.15       # 止损 15%
    take_profit_ratio: 0.10     # 止盈 10%
    pause_opening: false        # 暂停开仓
    auto_resume_after: 0        # 自动恢复时间（秒）
```

#### 功能说明

1. **持仓数量限制**：按币种数量限制（如：最多持有 4 个 PAXG）
2. **暂停/恢复开仓**：手动控制 Bot 的开仓操作
3. **实时仓位状态**：查看当前持仓、限制状态
4. **自动恢复**：设置暂停后自动恢复的时间
