# 回测任务失败（FAILED）常见原因

回测任务状态为 **FAILED** 时，服务端会把失败原因写入任务的 `error` 字段。在「回测 → 任务列表」中，将鼠标悬停在红色 **failed** 标签上可看到原因；点击「查看」后，结果区域会显示「任務執行失敗」及具体错误信息。

## 常见失败原因

| 错误信息（或含义） | 原因 | 处理建议 |
|------------------|------|----------|
| **獲取歷史數據失败** | 拉取 K 线失败（网络、交易所 API、配置等） | 检查网络与配置；可先在「K线缓存」预拉取该区间再回测 |
| **未獲取到历史數據** | 该时间区间没有 K 线（缓存未命中且接口返回空） | 确认时间范围在交易所有数据；或先生成 K 线缓存 |
| **price_high must be greater than price_low** | 网格策略：价格上限 ≤ 价格下限或未填 | 填写有效的價格下限、價格上限，且上限 > 下限 |
| **order_quantity and total_capital must be positive** | 网格：单笔数量或总资金 ≤ 0 | 填写大于 0 的初始资金与单笔数量 |
| **不支援的策略** | 策略名不在支持列表中 | 使用支持的策略：grid / dca / martingale / momentum / mean_reversion / trend_following |
| **回测執行失败** | 策略执行时报错（参数不合法等） | 查看完整 error 文案，按提示调整参数 |
| **創建結果目錄失败** / **保存結果失败** | 本地写文件失败 | 检查进程对 `backtest/results`、`backtest/reports` 的写权限与磁盘空间 |

## 如何查看具体失败原因

1. **任务列表**：鼠标悬停在该任务状态列的红色 **failed** 标签上，会显示 `error` 内容。
2. **结果区**：点击该任务的「查看」，下方会显示红色告警框「任務執行失敗」及完整错误信息。

相关逻辑：`backtest/task_manager.go`（`failTask`、`RunTask`）、`backtest/grid_adapter.go`（网格参数校验）。
