# 对账数据聚合功能说明

## 功能概述

对账页面新增了数据聚合功能，支持按日、按周、按月查看对账数据的趋势，并提供多指标曲线图展示。

## 主要特性

### 1. 数据视图切换

- **原始数据视图**: 显示所有对账记录的详细信息，保留原有的盈利曲线和仓位走势图
- **聚合数据视图**: 按时间维度聚合数据，显示趋势分析

### 2. 时间维度选择

在聚合数据视图下，支持三种时间维度：

- **按日**: 显示每日的平均数据和累计数据，默认查询最近30天
- **按周**: 显示每周的平均数据和累计数据，默认查询最近90天
- **按月**: 显示每月的平均数据和累计数据，默认查询最近12个月

### 3. 多指标图表

聚合数据视图提供两个主要图表：

#### 盈利趋势图
- 预计盈利曲线（蓝色）
- 实际盈利曲线（绿色）
- 支持点击图例切换显示/隐藏曲线
- 鼠标悬停显示详细数据

#### 持仓走势图
- 平均本地持仓曲线（蓝色）
- 平均交易所持仓曲线（绿色）
- 支持点击图例切换显示/隐藏曲线
- 鼠标悬停显示详细数据

### 4. 数据表格

聚合数据视图下的表格显示：
- 日期
- 平均本地持仓
- 平均交易所持仓
- 平均持仓差异
- 累计买入（该时间段内的最大值）
- 累计卖出（该时间段内的最大值）
- 预计盈利（该时间段内的最大值）
- 实际盈利（该时间段内的最大值）
- 记录数（该时间段内的对账记录数量）

## API 接口

### GET /api/reconciliation/aggregated

获取聚合的对账数据

**请求参数:**
- `period`: 聚合周期，可选值: `day`, `week`, `month`，默认 `day`
- `exchange`: 交易所名称（可选）
- `symbol`: 交易对（可选）
- `start_time`: 开始时间，ISO8601格式（可选）
- `end_time`: 结束时间，ISO8601格式（可选）

**响应格式:**
```json
{
  "data": [
    {
      "date": "2026-01-25",
      "avg_local_position": 0.1234,
      "avg_exchange_position": 0.1234,
      "avg_position_diff": 0.0000,
      "total_buy_qty": 10.50,
      "total_sell_qty": 10.00,
      "estimated_profit": 7.20,
      "actual_profit": 7.15,
      "record_count": 15
    }
  ]
}
```

## 数据聚合逻辑

### 平均值计算
- 本地持仓、交易所持仓、持仓差异：计算该时间段内所有记录的平均值

### 最大值选取
- 累计买入、累计卖出、预计盈利、实际盈利：选取该时间段内的最大值
- 原因：这些是累计指标，随时间递增，最大值代表该时间段结束时的累计值

### 日期格式
- 按日: `2026-01-25`
- 按周: `2026-W04` (ISO周编号)
- 按月: `2026-01`

## 使用场景

1. **长期趋势分析**: 通过按月聚合，快速了解长期盈利趋势
2. **周期性分析**: 通过按周聚合，识别周期性的盈利模式
3. **短期监控**: 通过按日聚合，监控近期的交易表现
4. **数据对比**: 在不同时间维度下对比盈利和持仓变化

## 技术实现

### 后端
- 新增 `getReconciliationAggregated` API处理函数
- 支持按日/周/月聚合对账历史数据
- 使用 Go 的 `time.ISOWeek()` 计算周编号

### 前端
- 新增视图模式状态管理（原始/聚合）
- 新增时间维度状态管理（日/周/月）
- 使用 SVG 绘制交互式图表
- 支持图例点击切换和鼠标悬停提示

## 注意事项

1. 聚合数据基于历史记录计算，需要有足够的对账历史数据
2. 时间范围会根据选择的聚合周期自动调整
3. 图表会自动适应数据范围，包括负值的正确显示
4. 累计指标（买入/卖出/盈利）取最大值，代表该时间段结束时的累计值
