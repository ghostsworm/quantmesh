# 付费推广与 Telegram 私域推广指南

本文档提供 QuantMesh 项目的付费推广和 Telegram 私域推广策略。

## 📱 Telegram 私域推广策略

### 1. Telegram 频道/群组推广

#### 方式一：加入相关群组并分享（免费/低成本）

**目标群组类型：**
- 加密货币交易群组
- 量化交易/算法交易群组
- Golang 开发者群组
- 技术开源项目群组
- 币圈投资交流群组

**寻找群组的方法：**
1. **Telegram 搜索**
   - 搜索关键词：`crypto trading`、`量化交易`、`algorithmic trading`、`golang`、`开源项目`
   - 使用 `@username` 格式搜索频道

2. **推荐平台**
   - [Telegram Channels](https://telegramchannels.me/)
   - [TGStat](https://tgstat.com/) - Telegram 频道统计
   - [Telegram Analytics](https://telegram-analytics.com/)

3. **中文社区**
   - 币圈相关群组（注意合规性）
   - 量化交易交流群
   - 技术开发者群组

**推广策略：**
```
✅ 正确做法：
- 先观察群组规则，了解是否允许推广
- 以"分享开源项目，征求反馈"的角度
- 提供有价值的内容（技术亮点、实战数据）
- 附上 GitHub 链接和简短说明
- 积极参与讨论，建立信任后再推广

❌ 避免：
- 直接发广告链接
- 刷屏式推广
- 忽略群组规则
- 纯广告性质的内容
```

**推广文案模板：**
```
大家好，我开源了一个高性能加密货币做市商系统 QuantMesh，想和大家分享：

✨ 核心特性：
• 支持 20+ 交易所（Binance、OKX、Bybit 等）
• WebSocket 驱动，延迟 <10ms
• $1亿+ 交易量实战验证
• 完整 React Web UI
• 多策略支持：网格、DCA、马丁格尔等

技术栈：Go + React + WebSocket

GitHub: https://github.com/ghostsworm/quantmesh
官网: https://quantmesh.io

欢迎 Star 和反馈！如有问题可以讨论。
```

#### 方式二：付费推广（Telegram 广告）

**Telegram 广告平台：**
1. **Telegram Ads**（官方广告）
   - 访问：https://promote.telegram.org/
   - 按展示付费（CPM）
   - 可以定向到特定频道
   - 最低预算：$2-5 美元

2. **第三方 Telegram 广告平台**
   - [Telegram Ads](https://telegram-ads.com/) - 非官方平台

   - 价格：通常 $50-500 美元/次推广

**推广渠道选择：**
- 选择与加密货币/量化交易相关的频道
- 查看频道订阅数和活跃度
- 确认频道受众与目标用户匹配

**广告文案建议：**
```

• 支持 20+ 交易所
```

## 📊 推广效果跟踪

### 关键指标（KPI）

1. **GitHub 指标**
   - Star 增长数
   - Fork 增长数
   - Watch 增长数
   - Issues/Discussions 参与度

2. **网站指标**
   - 访问量（UV/PV）
   - 跳出率
   - 停留时间
   - 转化率（访问 → Star）

3. **推广指标**
   - 广告点击率（CTR）
   - 每次点击成本（CPC）
   - 转化成本（CAC）
   - ROI（投资回报率）

### 跟踪工具

1. **GitHub Insights**
   - 仓库页面 → Insights
   - 查看流量来源

2. **Google Analytics**
   - 网站访问统计
   - 流量来源分析

3. **UTM 参数**
   - 在推广链接中添加 UTM 参数
   - 跟踪不同渠道效果

**UTM 参数示例：**
```
https://github.com/ghostsworm/quantmesh?utm_source=telegram&utm_medium=channel&utm_campaign=promo_2025
```
