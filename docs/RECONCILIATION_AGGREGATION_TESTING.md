# 对账数据聚合功能测试指南

## 测试前准备

1. 确保系统已经运行并有对账历史数据
2. 登录系统并进入对账页面

## 功能测试步骤

### 1. 视图切换测试

**测试步骤:**
1. 进入对账页面，默认显示"原始数据"视图
2. 点击"聚合数据"按钮
3. 验证页面切换到聚合数据视图

**预期结果:**
- 原始数据的盈利曲线和仓位走势图被隐藏
- 显示聚合数据的图表和表格
- 显示时间维度选择按钮（按日/按周/按月）

### 2. 按日聚合测试

**测试步骤:**
1. 在聚合数据视图下，选择"按日"
2. 等待数据加载完成
3. 查看图表和表格数据

**预期结果:**
- 显示最近30天的日度聚合数据
- 盈利趋势图显示每日的预计盈利和实际盈利
- 持仓走势图显示每日的平均持仓
- 表格显示每日的详细数据
- X轴显示日期格式如 "2026-01-25"

### 3. 按周聚合测试

**测试步骤:**
1. 在聚合数据视图下，选择"按周"
2. 等待数据加载完成
3. 查看图表和表格数据

**预期结果:**
- 显示最近90天的周度聚合数据
- 数据按周聚合显示
- X轴显示周格式如 "2026-W04"
- 每周的数据点代表该周所有对账记录的聚合

### 4. 按月聚合测试

**测试步骤:**
1. 在聚合数据视图下，选择"按月"
2. 等待数据加载完成
3. 查看图表和表格数据

**预期结果:**
- 显示最近12个月的月度聚合数据
- 数据按月聚合显示
- X轴显示月份格式如 "2026-01"
- 每月的数据点代表该月所有对账记录的聚合

### 5. 图表交互测试

**测试步骤:**
1. 在聚合数据视图下
2. 点击图例中的"预计盈利"
3. 验证预计盈利曲线隐藏/显示
4. 点击图例中的"实际盈利"
5. 验证实际盈利曲线隐藏/显示
6. 鼠标悬停在数据点上
7. 验证显示详细信息的提示框

**预期结果:**
- 点击图例可以切换曲线的显示/隐藏
- 鼠标悬停显示包含以下信息的提示框：
  - 日期
  - 预计盈利/实际盈利
  - 累计买入/累计卖出
  - 记录数

### 6. 持仓图表交互测试

**测试步骤:**
1. 在聚合数据视图下，查看持仓走势图
2. 点击图例中的"本地持仓"
3. 验证本地持仓曲线隐藏/显示
4. 点击图例中的"交易所持仓"
5. 验证交易所持仓曲线隐藏/显示
6. 鼠标悬停在数据点上
7. 验证显示详细信息的提示框

**预期结果:**
- 点击图例可以切换曲线的显示/隐藏
- 鼠标悬停显示包含以下信息的提示框：
  - 日期
  - 平均本地持仓
  - 平均交易所持仓
  - 平均持仓差异

### 7. 数据表格测试

**测试步骤:**
1. 在聚合数据视图下，滚动到表格部分
2. 验证表格显示的数据列

**预期结果:**
- 表格包含以下列：
  - 日期
  - 平均本地持仓
  - 平均交易所持仓
  - 平均持仓差异
  - 累计买入
  - 累计卖出
  - 预计盈利
  - 实际盈利
  - 记录数
- 持仓差异大于0.0001时显示为红色，否则为绿色
- 盈利为正数时显示为绿色，负数时显示为红色

### 8. 原始数据视图测试

**测试步骤:**
1. 点击"原始数据"按钮
2. 验证页面恢复到原始数据视图

**预期结果:**
- 显示原有的盈利曲线和仓位走势图
- 显示对账历史记录表格
- 时间维度选择按钮被隐藏

### 9. 交易对切换测试

**测试步骤:**
1. 在聚合数据视图下，切换不同的交易对
2. 验证数据自动刷新

**预期结果:**
- 切换交易对后，图表和表格数据自动更新
- 显示新交易对的聚合数据

### 10. 自动刷新测试

**测试步骤:**
1. 保持在聚合数据视图下
2. 等待10秒以上
3. 观察数据是否自动刷新

**预期结果:**
- 每10秒自动刷新一次数据
- 刷新时保持当前的视图模式和时间维度选择

## API测试

### 测试聚合API端点

使用curl或浏览器开发者工具测试API：

```bash
# 按日聚合
curl -X GET "http://localhost:8080/api/reconciliation/aggregated?period=day&symbol=BTCUSDT" \
  -H "Cookie: your-session-cookie"

# 按周聚合
curl -X GET "http://localhost:8080/api/reconciliation/aggregated?period=week&symbol=BTCUSDT" \
  -H "Cookie: your-session-cookie"

# 按月聚合
curl -X GET "http://localhost:8080/api/reconciliation/aggregated?period=month&symbol=BTCUSDT" \
  -H "Cookie: your-session-cookie"
```

**预期响应:**
```json
{
  "data": [
    {
      "date": "2026-01-25",
      "avg_local_position": 0.1234,
      "avg_exchange_position": 0.1234,
      "avg_position_diff": 0.0000,
      "total_buy_qty": 10.50,
      "total_sell_qty": 10.00,
      "estimated_profit": 7.20,
      "actual_profit": 7.15,
      "record_count": 15
    }
  ]
}
```

## 边界情况测试

### 1. 无数据情况
- 选择一个没有对账记录的交易对
- 验证页面显示空状态而不是错误

### 2. 数据量很少
- 选择只有1-2条对账记录的交易对
- 验证图表和表格能正常显示

### 3. 负盈利情况
- 验证负盈利值能正确显示（红色）
- 验证图表Y轴能正确显示负值范围

### 4. 持仓差异情况
- 验证有持仓差异时显示为红色
- 验证无持仓差异时显示为绿色

## 性能测试

1. 测试大量数据（1000+条记录）的聚合性能
2. 验证页面响应时间在可接受范围内
3. 验证图表渲染流畅，无卡顿

## 兼容性测试

在以下浏览器中测试：
- Chrome/Edge (最新版本)
- Firefox (最新版本)
- Safari (最新版本)

验证所有功能在不同浏览器中都能正常工作。
