# Bot 详情页概览增强需求

> **创建日期**: 2025-03-06  
> **状态**: 待实现

---

## 一、现状

Bot 详情页「概览」Tab 当前仅展示**全部累计**指标：

| 指标       | 说明                         |
|------------|------------------------------|
| 当前价格   | 实时市场价格                 |
| 未实现盈亏 | 当前持仓的浮动盈亏           |
| 总交易数   | 累计成交笔数                 |
| 总盈亏     | 累计已实现盈亏（网格自算口径）|

**缺失**：当日维度、多口径盈亏对比。

---

## 二、需求目标

在保持现有「全部」指标的基础上，增加**当日**维度和**多口径盈亏**展示，便于：

1. 快速查看当日表现
2. 对比「自算」与「交易所」口径，辅助对账与排查差异

---

## 三、新增指标

### 3.1 当日维度

| 指标         | 说明                         |
|--------------|------------------------------|
| 当日交易数   | 当日成交笔数                 |
| 当日盈亏(自算) | 当日网格口径已实现盈亏（trades 表） |
| 当日盈亏(交易所) | 当日交易所口径已实现盈亏（orders.realized_pnl） |

### 3.2 多口径盈亏（未实现部分）

当前「未实现盈亏」仅展示单一数值（优先交易所数据）。需求拆分为：

| 口径         | 说明                                   |
|--------------|----------------------------------------|
| 自算未实现盈亏 | 按槽位均价 × 当前价计算（slot_data）   |
| 交易所未实现盈亏 | 交易所 API 返回的持仓 unrealized_pnl   |

> 注：`getPositionsSummary` 已返回 `slot_data.unrealized_pnl` 与 `exchange_data.unrealized_pnl`，前端需在概览中同时展示。

### 3.3 「按交易所规则计划的盈亏」（可选）

用户提及：**我们自己按交易所的规则计划的盈亏**。

- **含义**：按交易所加权平均成本法模拟计算的盈亏，与交易所口径一致但由我方计算。
- **实现难度**：需在订单/成交层面按交易所规则重算，当前系统暂无该口径。
- **建议**：作为后续迭代，或通过「交易所返回」口径替代，待产品确认后再实现。

## 五、技术要点

### 5.1 后端

- **`GET /api/statistics`**：当 `exchange`、`symbol` 均指定时，新增返回字段：
  - `today_pnl`：当日自算盈亏（trades 表按日期聚合）
  - `today_exchange_pnl`：当日交易所盈亏（orders.realized_pnl 按日期聚合）
  - `today_trades`：当日成交笔数

- **`GET /api/positions/summary`**：已支持 `slot_data`、`exchange_data`，无需改动。

### 5.2 前端

- **BotDetail.tsx**：概览区增加「当日」卡片行，并展示未实现盈亏的双口径（自算 / 交易所）。
- **i18n**：新增 `botDetail.todayTrades`、`botDetail.todayPnlOurs`、`botDetail.todayPnlExchange`、`botDetail.unrealizedPnlOurs`、`botDetail.unrealizedPnlExchange` 等 key。
