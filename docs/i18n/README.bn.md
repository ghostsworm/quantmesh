| **উৎপাদন পরীক্ষিত** | $১০০M+ ট্রেডিং ভলিউম | পরীক্ষিত নয় |

- ✅ **যুদ্ধ-পরীক্ষিত**: $১০০M+ ট্রেডিং ভলিউম দিয়ে প্রমাণিত

## 📖 পরিচিতি

QuantMesh হল একটি উচ্চ-কর্মক্ষমতা, নিম্ন-বিলম্ব ক্রিপ্টোকারেন্সি মার্কেট মেকার সিস্টেম যা পারপেচুয়াল কন্ট্রাক্ট মার্কেটের জন্য দীর্ঘ গ্রিড ট্রেডিং কৌশলের উপর ফোকাস করে। Go-তে বিকশিত এবং WebSocket রিয়েল-টাইম ডেটা স্ট্রিম দ্বারা চালিত, এটি Binance, Bitget এবং Gate.io এর মতো প্রধান এক্সচেঞ্জগুলির জন্য স্থিতিশীল তরলতা সমর্থন প্রদানের লক্ষ্য রাখে।

কয়েকটি পুনরাবৃত্তির পরে, আমরা এই সিস্টেমটি ব্যবহার করে $১০০ মিলিয়নের বেশি ভার্চুয়াল মুদ্রা ট্রেড করেছি। উদাহরণস্বরূপ, শূন্য ফি সহ Binance ETHUSDC ট্রেডিং, $১ মূল্য ব্যবধান এবং প্রতি অর্ডারে $৩০০, দৈনিক ট্রেডিং ভলিউম $৩ মিলিয়ন অতিক্রম করতে পারে এবং প্রতি মাসে $৫০ মিলিয়নের বেশি। যতক্ষণ বাজার দোলায়িত হয় বা ঊর্ধ্বমুখী থাকে, এটি লাভ তৈরি করতে থাকবে। যদি বাজার একতরফাভাবে পড়ে, $৩০,০০০ মার্জিন ১০০০ পয়েন্টের পতনের জন্য কোনও লিকুইডেশন নিশ্চিত করতে পারে। খরচ কমানোর জন্য অবিচ্ছিন্ন ট্রেডিংয়ের মাধ্যমে, ৫০% পুনরুদ্ধার ব্রেক-ইভেন পৌঁছানোর জন্য যথেষ্ট, এবং মূল খোলার মূল্যে ফিরে আসা উল্লেখযোগ্য লাভ উৎপাদন করতে পারে। যদি একটি একতরফা দ্রুত পতন থাকে, সক্রিয় ঝুঁকি নিয়ন্ত্রণ সিস্টেমটি স্বয়ংক্রিয়ভাবে সনাক্ত করবে এবং অবিলম্বে ট্রেডিং বন্ধ করবে, বাজার পুনরুদ্ধার হলে শুধুমাত্র অবিচ্ছিন্ন অর্ডার অনুমোদন করবে, মূল্য স্পাইক থেকে লিকুইডেশন নিয়ে চিন্তা না করে।

উদাহরণ: ৩০০০ পয়েন্টে ETH ট্রেডিং শুরু করা, মূল্য ২৭০০ পয়েন্টে পড়ে, প্রায় $৩,০০০ হারানো। যখন মূল্য ২৮৫০ পয়েন্টের উপরে পুনরুদ্ধার হয়, এটি ব্রেক-ইভেন পৌঁছায়। ৩০০০ পয়েন্টে ফিরে আসা, লাভ $১,০০০ থেকে $৩,০০০ পর্যন্ত পরিবর্তিত হয়।

## 📜 প্রকল্পের উৎস

এই প্রকল্পটি মূলত [OpenSQT Market Maker](https://github.com/dennisyang1986/opensqt_market_maker) এর উপর ভিত্তি করে বিকশিত হয়েছিল, [dennisyang1986](https://github.com/dennisyang1986) দ্বারা MIT লাইসেন্সের অধীনে প্রকাশিত।

মূল প্রকল্পের উপর ভিত্তি করে, আমরা নিম্নলিখিত প্রধান উন্নতি এবং সম্প্রসারণ করেছি:

- ✨ **সম্পূর্ণ ফ্রন্টএন্ড ইন্টারফেস**: একটি React + TypeScript ওয়েব ম্যানেজমেন্ট ইন্টারফেস যোগ করা হয়েছে যা ভিজ্যুয়াল ট্রেডিং মনিটরিং, কনফিগারেশন ম্যানেজমেন্ট এবং ডেটা বিশ্লেষণ প্রদান করে
- 🏦 **এক্সচেঞ্জ সম্প্রসারণ**: মূল প্রকল্পের ৩টি এক্সচেঞ্জ (Binance, Bitget, Gate.io) থেকে **২০+ প্রধান এক্সচেঞ্জ** এ প্রসারিত
- 🔒 **আর্থিক-স্তরের স্থিতিশীলতা**: সিস্টেমের নির্ভরযোগ্যতা ব্যাপকভাবে উন্নত করা হয়েছে, যার মধ্যে রয়েছে ব্যাপক ত্রুটি পরিচালনা, সমবর্তী নিরাপত্তা মেকানিজম, ডেটা সামঞ্জস্য গ্যারান্টি, স্বয়ংক্রিয় পুনরুদ্ধার ইত্যাদি
- 📊 **উন্নত মনিটরিং**: উন্নত লগিং সিস্টেম, মেট্রিক সংগ্রহ (Prometheus), স্বাস্থ্য পরীক্ষা এবং রিয়েল-টাইম সতর্কতা
- 🛡️ **শক্তিশালী ঝুঁকি নিয়ন্ত্রণ**: মাল্টি-স্তর ঝুঁকি মনিটরিং, স্বয়ংক্রিয় সমন্বয়, অস্বাভাবিকতা সার্কিট ব্রেকার এবং তহবিল নিরাপত্তা সুরক্ষা
- 🔌 **প্লাগইন সিস্টেম**: সহজ কাস্টমাইজেশন এবং মাধ্যমিক উন্নয়নের জন্য প্রসারযোগ্য প্লাগইন মেকানিজমের জন্য সমর্থন
- 📱 **আন্তর্জাতিকীকরণ সমর্থন**: মাল্টি-ভাষা ইন্টারফেস (চীনা/ইংরেজি), i18n সমর্থন
- 🧪 **টেস্টনেট সমর্থন**: উন্নয়ন এবং পরীক্ষার জন্য একাধিক এক্সচেঞ্জের টেস্টনেট পরিবেশের জন্য সমর্থন

## ✨ মূল বৈশিষ্ট্য

- **মাল্টি-এক্সচেঞ্জ সমর্থন**: Binance, Bitget, Gate.io, Bybit, EdgeX এবং অন্যান্য প্রধান প্ল্যাটফর্মের সাথে সামঞ্জস্যপূর্ণ।
- **মিলিসেকেন্ড-স্তরের প্রতিক্রিয়া**: সম্পূর্ণ WebSocket-চালিত (বাজার ডেটা এবং অর্ডার ফ্লো), পোলিং বিলম্ব দূর করে।
- **স্মার্ট গ্রিড কৌশল**: 
  - **স্থির পরিমাণ মোড**: আরও নিয়ন্ত্রণযোগ্য মূলধন ব্যবহার।
  - **সুপার স্লট সিস্টেম**: বুদ্ধিমানের সাথে অর্ডার এবং অবস্থান অবস্থা পরিচালনা করে, সমবর্তীতা দ্বন্দ্ব প্রতিরোধ করে।
- **শক্তিশালী ঝুঁকি নিয়ন্ত্রণ সিস্টেম**:
  - **সক্রিয় ঝুঁকি নিয়ন্ত্রণ**: K-line ভলিউম অস্বাভাবিকতার রিয়েল-টাইম মনিটরিং, স্বয়ংক্রিয়ভাবে ট্রেডিং বিরতি দেয়।
  - **তহবিল নিরাপত্তা**: স্টার্টআপের আগে স্বয়ংক্রিয়ভাবে ব্যালেন্স, লিভারেজ এবং সর্বোচ্চ অবস্থান ঝুঁকি পরীক্ষা করে।
  - **স্বয়ংক্রিয় সমন্বয়**: ডেটা সামঞ্জস্য নিশ্চিত করতে স্থানীয় এবং এক্সচেঞ্জ অবস্থা নিয়মিত সিঙ্ক্রোনাইজ করে।
- **উচ্চ-সমবর্তীতা আর্কিটেকচার**: Goroutine + Channel + Sync.Map এর উপর ভিত্তি করে দক্ষ সমবর্তীতা মডেল।

## সেরা অনুশীলন

1. **এক্সচেঞ্জ VIP অবস্থার জন্য**: এই সিস্টেমটি একটি ভলিউম জেনারেশন টুল। যদি মূল্য ওঠানামা বড় না হয়, $৩,০০০ মার্জিন ২-৩ দিনে $১০ মিলিয়ন ট্রেডিং ভলিউম তৈরি করতে পারে।

2. **লাভের জন্য সেরা অনুশীলন**: একটি পতনের পর বাজারে প্রবেশ করুন। প্রথমে একটি অবস্থান কিনুন, তারপর সফ্টওয়্যার শুরু করুন। এটি স্বয়ংক্রিয়ভাবে গ্রিড দ্বারা গ্রিড উপরে বিক্রি করবে। যখন আপনার অবস্থান বিক্রি হয়ে যায়, সিস্টেম বন্ধ করুন। আপনি যদি নিশ্চিত না হন যে বর্তমান বাজার একটি নিম্ন বিন্দু, আপনি একটি বেস অবস্থান ছাড়াই শুরু করতে পারেন। যদি এটি আরও পড়ে, নিম্ন বিন্দুতে একটি অবস্থান যোগ করুন এবং বিক্রি চালিয়ে যেতে পুনরায় শুরু করুন। এটি লাভ সর্বাধিক করে। অবিচ্ছিন্ন লাভের জন্য এই চক্রটি পুনরাবৃত্তি করুন। পতনের বিষয়ে চিন্তা করবেন না - প্রোগ্রামটি অবিচ্ছিন্নভাবে খরচ কমায়। যতক্ষণ এটি অর্ধেক পুনরুদ্ধার করে, আপনি ব্রেক-ইভেন পৌঁছান।

## 🚀 শুরু করা

### পূর্বশর্ত
- Go ১.২১ বা উচ্চতর
- এক্সচেঞ্জ API-তে অ্যাক্সেস করতে সক্ষম নেটওয়ার্ক পরিবেশ

### ইনস্টলেশন

1. **রিপোজিটরি ক্লোন করুন**
   ```bash
   git clone https://github.com/ghostsworm/quantmesh.git
   cd quantmesh
   ```

2. **নির্ভরতা ইনস্টল করুন**
   ```bash
   go mod download
   ```

### কনফিগারেশন

> **Runtime SSOT:** The primary database table `app_config` holds the authoritative configuration. One-time YAML import: `./quantmesh --migrate-app-config` (with `QUANTMESH_IMPORT_YAML`, or `config.yaml` in the working directory), or run `./quantmesh /path/to/file.yaml` as the first argument. See [`docs/config-database-design.md`](../config-database-design.md).

1. উদাহরণ কনফিগারেশন ফাইল কপি করুন:
   ```bash
   cp docs/config/examples/config.example.yaml config.yaml
   ```

2. `config.yaml` সম্পাদনা করুন এবং আপনার API Key এবং কৌশল পরামিতি পূরণ করুন:

   ```yaml
   app:
     current_exchange: "binance"  # এক্সচেঞ্জ নির্বাচন করুন

   exchanges:
     binance:
       api_key: "YOUR_API_KEY"
       secret_key: "YOUR_SECRET_KEY"
       fee_rate: 0.0002

   trading:
     symbol: "ETHUSDT"       # ট্রেডিং জোড়া
     price_interval: 2       # গ্রিড ব্যবধান (মূল্য)
     order_quantity: 30     # প্রতি গ্রিড পরিমাণ (USDT)
     buy_window_size: 10    # ক্রয় অর্ডারের সংখ্যা
     sell_window_size: 10   # বিক্রয় অর্ডারের সংখ্যা
   ```

### ব্যবহার

#### উৎপাদন মোড

সংকলিত বাইনারি চালান:

```bash
go run main.go
```

অথবা তৈরি করুন এবং চালান:

```bash
go build -o quantmesh
```

**বিকল্প ১: উন্নয়ন স্ক্রিপ্ট ব্যবহার করুন (সুপারিশকৃত)**

```bash
./scripts/local/dev.sh
```

- পোর্ট ২৮৮৮৮-এ Go ব্যাকএন্ড সার্ভার শুরু করবে
- পোর্ট ১৫১৭৩-এ Vite dev সার্ভার শুরু করবে
- ফ্রন্টএন্ড কোড পরিবর্তনের জন্য হট রিলোড সক্ষম করবে
- ডিবাগিংয়ের জন্য সোর্স ম্যাপ প্রদান করবে (কোনও মিনিফাইড কোড নেই)

তারপর অ্যাপ্লিকেশনে অ্যাক্সেস করুন: **http://localhost:15173**

```bash
cd webui
```

তারপর অ্যাপ্লিকেশনে অ্যাক্সেস করুন: **http://localhost:15173**

**উন্নয়ন মোড সুবিধা:**

- ❌ **IP ঠিকানা**: ফ্রন্টএন্ড IP ক্যাপচার নিষ্ক্রিয়, ব্যাকএন্ড IP এর পরিবর্তে ইনস্ট্যান্স ID ব্যবহার করে
- ❌ **ভৌগোলিক অবস্থান**: অক্ষাংশ/দ্রাঘিমাংশ, শহর বা অন্যান্য অবস্থান তথ্য সংগ্রহ নেই
- ❌ **ব্যক্তিগত তথ্য**: ব্যবহারকারী ID, ইমেইল, নাম বা কোনও পরিচয় তথ্য সংগ্রহ নেই
- ❌ **সংবেদনশীল ডেটা**: API কী, ট্রেডিং পরিমাণ, অ্যাকাউন্ট ব্যালেন্স বা অবস্থান তথ্য সংগ্রহ নেই
- ❌ **আর্থিক ডেটা**: কোনও আর্থিক বা ট্রেডিং সংবেদনশীল তথ্য সংগ্রহ নেই

### 🛡️ গোপনীয়তা সুরক্ষা ব্যবস্থা

1. **ইনস্ট্যান্স ID মেকানিজম**: অনন্য পরিচয়কারী হিসাবে এলোমেলোভাবে তৈরি UUID ব্যবহার করে, `./data/instance_id` ফাইলে সংরক্ষিত, কোনও ব্যক্তিগত তথ্য নেই
2. **ফ্রন্টএন্ড IP নিষ্ক্রিয়**: PostHog SDK `ip_capture: false` দিয়ে কনফিগার করা, IP ঠিকানা ক্যাপচার এবং ভৌগোলিক অবস্থান অনুমান নিষ্ক্রিয় করে
3. **ব্যাকএন্ড IP পাঠায় না**: ব্যাকএন্ড কোড পরিসংখ্যান পরিষেবাতে IP ঠিকানা পাঠায় না
4. **সম্পূর্ণ ঐচ্ছিক**: ব্যবহারকারীরা যে কোনও সময় পরিবেশ পরিবর্তনশীলের মাধ্যমে পরিসংখ্যান নিষ্ক্রিয় করতে পারেন
5. **কোড স্বচ্ছতা**: সমস্ত পরিসংখ্যান কোড যাচাইযোগ্য, `utils/telemetry.go` এ অবস্থিত

### ⚙️ কীভাবে পরিসংখ্যান নিষ্ক্রিয় করবেন

**পদ্ধতি ১: পরিবেশ পরিবর্তনশীল (সুপারিশকৃত)**
```bash
export QUANTMESH_DISABLE_TELEMETRY=1
```

**পদ্ধতি ২: ফ্রন্টএন্ড নিষ্ক্রিয় করুন**
`webui/.env.local` ফাইলে:
```bash
VITE_DISABLE_TELEMETRY=1
```

**পদ্ধতি ৩: কোড পরিবর্তন করুন**
`utils/telemetry.go` সম্পাদনা করুন, `Enabled` কে `false` এ সেট করুন
