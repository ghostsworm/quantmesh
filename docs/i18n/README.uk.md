## 📖 Вступ

QuantMesh — це високопродуктивна система маркет-мейкера криптовалют з низькою затримкою, що фокусується на довгострокових стратегіях сіткової торгівлі для ринків перпетуальних контрактів. Розроблена на Go і працює на потоках даних WebSocket у реальному часі, мета — забезпечити стабільну підтримку ліквідності для великих бірж, таких як Binance, Bitget та Gate.io.

Після кількох ітерацій ми використовували цю систему для торгівлі понад $100 мільйонів у віртуальній валюті. Наприклад, торгівля Binance ETHUSDC з нульовими комісіями, інтервалом ціни $1 та $300 на ордер, щоденний торговий об'єм може перевищувати $3 мільйони та понад $50 мільйонів на місяць. Поки ринок коливається або має тенденцію до зростання, він продовжуватиме генерувати прибуток. Якщо ринок впаде односторонньо, $30,000 маржі може гарантувати відсутність ліквідації при падінні на 1000 пунктів. Через безперервну торгівлю для зниження витрат, відновлення на 50% достатньо для виходу в нуль, а повернення до початкової ціни відкриття може принести значний прибуток. Якщо є одностороннє швидке падіння, активна система контролю ризиків автоматично ідентифікує та негайно зупинить торгівлю, дозволяючи продовжувати ордери лише коли ринок відновиться, без занепокоєння щодо ліквідації від сплесків цін.

Приклад: Початок торгівлі ETH на рівні 3000 пунктів, ціна падає до 2700 пунктів, втрата приблизно $3,000. Коли ціна відновлюється вище 2850 пунктів, досягається нуль. Повернення до 3000 пунктів, прибуток коливається від $1,000 до $3,000.

## 📜 Походження проекту

Цей проект був спочатку розроблений на основі [OpenSQT Market Maker](https://github.com/dennisyang1986/opensqt_market_maker), опублікованого [dennisyang1986](https://github.com/dennisyang1986) під ліцензією MIT.

На основі оригінального проекту ми внесли наступні основні покращення та розширення:

- ✨ **Повний інтерфейс Frontend**: Додано веб-інтерфейс управління React + TypeScript, що забезпечує візуальний моніторинг торгівлі, управління конфігурацією та аналіз даних
- 🏦 **Розширення бірж**: Розширено з 3 бірж (Binance, Bitget, Gate.io) в оригінальному проекті до **20+ великих бірж**
- 🔒 **Фінансова стабільність**: Комплексно покращено надійність системи, включаючи комплексну обробку помилок, механізми безпеки паралельності, гарантії узгодженості даних, автоматичне відновлення тощо
- 📊 **Покращений моніторинг**: Покращена система логування, збір метрик (Prometheus), перевірки здоров'я та сповіщення в реальному часі
- 🛡️ **Посилений контроль ризиків**: Багатошаровий моніторинг ризиків, автоматичне узгодження, захист від аномалій та захист безпеки коштів
- 🔌 **Система плагінів**: Підтримка розширюваних механізмів плагінів для легкого налаштування та вторинної розробки
- 📱 **Підтримка інтернаціоналізації**: Багатомовний інтерфейс (китайська/англійська), підтримка i18n
- 🧪 **Підтримка Testnet**: Підтримка середовищ testnet кількох бірж для розробки та тестування

Для детальних описів покращень та інформації про стороннє програмне забезпечення див. файл [NOTICE](../../NOTICE).

## ✨ Ключові функції

- **Підтримка кількох бірж**: Сумісний з Binance, Bitget, Gate.io, Bybit, EdgeX та іншими великими платформами.
- **Відповідь на рівні мілісекунд**: Повністю на базі WebSocket (ринкові дані та потік ордерів), усуваючи затримки polling.
- **Розумна сіткова стратегія**: 
  - **Режим фіксованої суми**: Більш контрольоване використання капіталу.
  - **Система Super Slot**: Розумно керує станами ордерів та позицій, запобігаючи конфліктам паралельності.
- **Потужна система контролю ризиків**:
  - **Активний контроль ризиків**: Моніторинг у реальному часі аномалій об'єму K-line, автоматичне призупинення торгівлі.
  - **Безпека коштів**: Автоматично перевіряє баланс, кредитне плече та максимальний ризик позиції перед запуском.
  - **Автоматичне узгодження**: Регулярно синхронізує локальні та біржові стани для забезпечення узгодженості даних.
- **Архітектура високої паралельності**: Ефективна модель паралельності на основі Goroutine + Channel + Sync.Map.

## Найкращі практики

1. **Для VIP статусу біржі**: Ця система є інструментом генерації об'єму. Якщо коливання цін невеликі, $3,000 маржі може генерувати $10 мільйонів торгового об'єму за 2-3 дні.

2. **Найкраща практика для прибутку**: Входьте на ринок після раунду падіння. Спочатку купіть позицію, потім запустіть програмне забезпечення. Воно автоматично продаватиме сітку за сіткою вгору. Коли ваша позиція буде продана, зупиніть систему. Якщо ви не впевнені, чи поточний ринок є низькою точкою, ви можете почати без базової позиції. Якщо він впаде далі, додайте позицію в низькій точці та перезапустіть для продовження продажу. Це максимізує прибуток. Повторюйте цей цикл для постійного прибутку. Не хвилюйтеся про падіння — програма постійно знижує витрати. Поки вона відновлюється на половину, ви виходите в нуль.

## 🚀 Початок роботи

### Передумови
- Go 1.21 або вище
- Мережеве середовище, здатне отримувати доступ до API бірж

### Встановлення

1. **Клонуйте репозиторій**
   ```bash
   git clone https://github.com/ghostsworm/quantmesh.git
   cd quantmesh
   ```

2. **Встановіть залежності**
   ```bash
   go mod download
   ```

### Конфігурація

1. Скопіюйте приклад конфігураційного файлу:
   ```bash
   cp config.example.yaml config.yaml
   ```

2. Відредагуйте `config.yaml` та заповніть ваш API Key та параметри стратегії:

   ```yaml
   app:
     current_exchange: "binance"  # Виберіть біржу

   exchanges:
     binance:
       api_key: "YOUR_API_KEY"
       secret_key: "YOUR_SECRET_KEY"
       fee_rate: 0.0002

   trading:
     symbol: "ETHUSDT"       # Торгова пара
     price_interval: 2       # Інтервал сітки (ціна)
     order_quantity: 30     # Сума на сітку (USDT)
     buy_window_size: 10    # Кількість ордерів на купівлю
     sell_window_size: 10   # Кількість ордерів на продаж
   ```

### Використання

#### Режим продакшену

Запустіть скомпільований бінарний файл:

```bash
go run main.go
```

Або зберіть та запустіть:

```bash
go build -o quantmesh
./quantmesh
```

Backend буде обслуговувати статичні файли frontend на порту 28888 (за замовчуванням).

#### Режим розробки

Для розробки frontend з hot reload та відлагодженням вихідного коду:

**Варіант 1: Використовуйте скрипт розробки (Рекомендовано)**

```bash
./dev.sh
```

Цей скрипт:
- Запустить сервер backend Go на порту 28888
- Запустить сервер dev Vite на порту 15173
- Увімкне hot reload для змін коду frontend
- Надасть source maps для відлагодження (без мінімізованого коду)

Потім отримайте доступ до додатку за адресою: **http://localhost:15173**

**Варіант 2: Ручний запуск**

Термінал 1 - Запустіть backend Go:
```bash
go run main.go
```

Термінал 2 - Запустіть сервер dev Vite:
```bash
cd webui
pnpm dev
```

Потім отримайте доступ до додатку за адресою: **http://localhost:15173**

**Переваги режиму розробки:**
- ✅ Hot reload - Зміни коду frontend миттєво відображаються
- ✅ Source maps - Відлагодження з оригінальним кодом TypeScript/React (не мінімізованим)
- ✅ Швидке оновлення - Компоненти React оновлюються без втрати стану
- ✅ Кращі повідомлення про помилки - Бачите фактичні імена файлів та номери рядків

**Примітка:** У режимі розробки сервер dev Vite проксує запити API (`/api/*`) та з'єднання WebSocket (`/ws`) до backend Go, що працює на порту 28888.

## 📊 Статистика використання та захист конфіденційності

QuantMesh включає опціональну функцію статистики використання для збору анонімних даних використання, допомагаючи нам зрозуміти використання проекту та покращити продукт. **Весь збір даних повністю прозорий, код підлягає аудиту та може бути вимкнений у будь-який час.**

### 🔒 Захист конфіденційності

**Дані, які ми збираємо (Анонімні):**
- ✅ **Базова інформація**: Номер версії, операційна система, архітектура, ID екземпляра (випадково згенерований UUID)
- ✅ **Статистика використання**: Використовувані назви бірж, торгові пари
- ✅ **Метрики продуктивності**: Затримка запиту/відповіді API, затримка WebSocket
- ✅ **Торгова активність**: Напрямок торгівлі (купівля/продаж), виключаючи торгові суми

**Дані, які ми НЕ збираємо:**
- ❌ **IP-адреса**: Frontend має вимкнений захоплення IP, backend використовує ID екземпляра замість IP
- ❌ **Геолокація**: Немає збору широти/довготи, міста або іншої інформації про місцезнаходження
- ❌ **Особиста інформація**: Немає збору ID користувачів, електронних листів, імен або будь-якої інформації про ідентичність
- ❌ **Чутливі дані**: Немає збору API ключів, торгових сум, балансів рахунків або інформації про позиції
- ❌ **Фінансові дані**: Немає збору будь-якої фінансової або чутливої торгової інформації

### 🛡️ Заходи захисту конфіденційності

1. **Механізм ID екземпляра**: Використовує випадково згенерований UUID як унікальний ідентифікатор, зберігається у файлі `./data/instance_id`, не містить особистої інформації
2. **IP Frontend вимкнено**: PostHog SDK налаштований з `ip_capture: false`, вимикаючи захоплення IP-адреси та виведення геолокації
3. **Backend не надсилає IP**: Код backend не надсилає IP-адреси до служби статистики
4. **Повністю опціонально**: Користувачі можуть вимкнути статистику у будь-який час через змінні середовища
5. **Прозорість коду**: Весь код статистики підлягає аудиту, знаходиться в `utils/telemetry.go`

### ⚙️ Як вимкнути статистику

**Метод 1: Змінна середовища (Рекомендовано)**
```bash
export QUANTMESH_DISABLE_TELEMETRY=1
```

**Метод 2: Вимкнути Frontend**
У файлі `webui/.env.local`:
```bash
VITE_DISABLE_TELEMETRY=1
```

**Метод 3: Змінити код**
Відредагуйте `utils/telemetry.go`, встановіть `Enabled` на `false`

- Користувачі несуть повну відповідальність за будь-які прибутки або збитки від використання цього програмного забезпечення.
- Завжди ретельно тестуйте на Testnet перед використанням реальних коштів.
- Розробники не несуть відповідальності за збитки через помилки програмного забезпечення, затримки мережі або збої бірж.

- **BTC** (Bitcoin)
- **ETH** (Ethereum)
- **USDT** (Tether, ERC20)
- **USDC** (USD Coin, ERC20)

### Методи оплати
1. **Coinbase Commerce** (Рекомендовано)
   - Автоматичне підтвердження
   - Підтримка кількох криптовалют
   - Легка сторінка оплати

2. **Прямий платіж гаманця**
   - Без участі третіх сторін
   - Більше конфіденційності
   - Ручне підтвердження (1-24 години)

### Швидкий старт
```bash

# 1. Зареєструйтеся на https://commerce.coinbase.com
# 2. Налаштуйте API Key у .env.crypto
# 3. Запустіть службу

# Метод B: Прямий гаманець (5 хвилин)
# 1. Налаштуйте адреси гаманця
# 2. Запустіть службу
# 3. Ручне підтвердження
```
